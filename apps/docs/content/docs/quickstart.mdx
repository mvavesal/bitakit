---
title: 1. Create an app
description: Start a minimal Next.js app before adding your first plugin.
---

You need **Node.js 24** and **npm 10 or newer**. This walkthrough uses Next.js and no optional features.

<Callout title="Use matching packages">
  These examples target the 0.2 API. Keep all `@bitakit/*` packages on the same version. To try
  changes from this repository that are not released yet, use the
  [local package setup](/docs/local-development).
</Callout>

## 1. Create the project

```sh
npx @bitakit/create-app my-app --framework next --features none --yes
```

Use a new directory name, or `.` for an empty folder you already have open (for example in a coding agent). The generator connects BitaKit and keeps your normal Next.js routes.

## 2. Start the app

```sh
cd my-app
npm run dev
```

Open the address printed in the terminal. You should see **Welcome**.

## 3. Make one visible change

Replace `src/app/page.tsx` with:

```tsx
'use client';
import { PageHeader } from '@bitakit/ui/components';

export default function Home() {
  return <PageHeader title="My first app" />;
}
```

The page now says **My first app**. Keep the generated provider and configuration as they are.

## 4. Check your project

In a second terminal, from the app directory:

```sh
npm run typecheck
npx bitakit doctor
```

`typecheck` generates the plugin types and checks your code. `doctor` reports wiring problems with suggested fixes.
