title: Architecture map
description: See which layer owns execution, state, rendering and discovery.
---

Use this map after the [small Counter tutorial](/docs/concepts).
You do not need to configure every layer to create a plugin.

<Figure name="layers" />

| Part                    | Owns                                                                               | Does not own                                      |
| ----------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------- |
| Discovery               | File parsing, generated imports/types and package metadata                         | Browser execution or runtime package installation |
| Core                    | Lifecycle, services, Action execution, events, Settings values and slot attachment | React or rendering                                |
| UI bindings             | Reactive reads, bound controls, contextual slot selection                          | Product layout or a second value store            |
| Shell / App Preferences | App frame, region outlets and Settings presentation                                | A second runtime or routing engine                |
| Host                    | Composition, native routes, central theme and trusted server integration           | Per-plugin bootstrap registries                   |
