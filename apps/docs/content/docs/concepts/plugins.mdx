---
title: 2. Add a page
description: Create a plugin with a single page file.
---

Start in the minimal app from the [quickstart](/docs/quickstart).
A **plugin** groups the files for one feature. Start with just a page; add behavior only when
you need it. We will grow one plugin called **counter** throughout these lessons.

[Read more about plugin files →](/docs/concepts/discovery)

## 1. Create one file

Create `src/plugins/counter/ui/pages/index.tsx`:

```tsx
'use client';
import { PageHeader } from '@bitakit/ui/components';

export default function CounterPage() {
  return <PageHeader title="Counter" />;
}
```

## 2. Open the page

With the dev server running, visit **`/counter`**. You should see the Counter heading.
If you create files while the server is stopped, `npm run typecheck` generates their types before checking them.

That single file is a plugin. Its folder supplies the name; discovery connects its page.

```text
src/plugins/counter/
└── ui/pages/index.tsx   → /counter
```

## 3. Understand the names

| Path                   | Meaning                            |
| ---------------------- | ---------------------------------- |
| `counter/`             | Plugin ID `counter`                |
| `ui/pages/index.tsx`   | The plugin's root page, `/counter` |
| `ui/pages/history.tsx` | Another page, `/counter/history`   |

Only create the files the feature needs. A `plugin.config.ts`, service, Action, event or slot is not required to show this page.

## What you have now

- **This step gave you** the plugin `counter` (its folder) and the page `/counter`, served by the
  adapter's catch-all route. Nothing was registered by hand.
- **Others extend it** by linking to the page, for example with an Action whose `href` is
  `/counter` in their own folder.

**Next:** [Give the Counter a value →](/docs/concepts/services)

## Later: scaffold a larger feature

`npx bitakit add plugin notes --example` creates a fuller example with a service, events, Actions and a page.
It is useful once those concepts are familiar. For the learning path, continue growing the Counter one file at a time.

For explicit dependencies or a reusable package, see the [service reference](/docs/reference/services)
and [package guide](/docs/packages).
