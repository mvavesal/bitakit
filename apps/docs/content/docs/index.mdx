BitaKit is a modular app framework. It provides a framework-independent runtime, Actions and typed services.
Optional packages add React bindings, settings, application shells and provider integrations.
Your application owns its business behavior and native routes.

## Start here

[Follow the quickstart](/docs/quickstart) for the intended application setup flow. Then learn the [Core concepts](/docs/concepts) and follow the [To-do walkthrough](/docs/concepts/tutorial). Use the [package guide](/docs/packages) to see which package owns each capability.

## How the pieces fit

- **Core** manages plugin lifecycle, Actions and shared service contracts.
- **UI** connects the runtime to React. Framework integrations connect navigation.
- **Plugins** own their functionality and translations. Install only the capabilities you need.
- **Your app** supplies product behavior, routes and configuration.

## Current availability

The repository records Core 0.1.0 as published. These guides also describe newer workspace APIs, including events. The generator and other packages remain release previews.
The quickstart clearly marks the installation commands as a release preview.
Next.js generation currently uses Webpack. TanStack Start is experimental.
