![BitaKit — Your app. Your building blocks.](/brand/bitakit-banner.png)

Build your next feature with less wiring. BitaKit connects your services, actions and plugins while you keep your framework and your app's behavior.

Start small: create a service, add an action, and bind it. TypeScript carries the types from your definition to the caller. Add settings, an app shell or integrations when you need them.

## Start here

[Create your app](/docs/quickstart) with one command. Then [build your first plugin](/docs/concepts/plugins) in two files.

New to the terms? [Core concepts](/docs/concepts) explains each piece. Curious how Core works without a framework? The [To-do walkthrough](/docs/concepts/tutorial) runs it in plain Node (advanced).

## How the pieces fit

- **Core** manages plugin lifecycle, services, actions, events and shared contracts.
- **UI** connects the runtime to React. Framework integrations connect navigation and run discovery at build time.
- **Plugins** own their functionality, UI and translations. Install only the capabilities you need.
- **Your app** supplies product behavior, routes and configuration.

## Current availability

The generator and the BitaKit packages are available on npm (0.1). These guides describe
the next release, 0.2, which changes the plugin API; it is not on npm yet. TanStack Start is
experimental.
