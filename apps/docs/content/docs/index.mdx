![BitaKit — Your app. Your building blocks.](/brand/bitakit-banner.png)

Build your next feature with less wiring. BitaKit connects your services, actions and plugins while you keep your framework and your app's behavior.

Start small: create a service, add an action, and use it. TypeScript carries the types from your definition to the caller. Add settings, an app shell or integrations when you need them.

## Start here

[Create your app](/docs/quickstart) with one command. Then [build your first plugin](/docs/concepts/plugins) in two files.

New to the terms? [Core concepts](/docs/concepts) explains each piece. Curious how Core works without a framework? The [To-do walkthrough](/docs/concepts/tutorial) runs it in plain Node (advanced).

## How the pieces fit

- **Core** manages plugin lifecycle, Actions and shared service contracts.
- **UI** connects the runtime to React. Framework integrations connect navigation.
- **Plugins** own their functionality and translations. Install only the capabilities you need.
- **Your app** supplies product behavior, routes and configuration.

## Current availability

The generator and the BitaKit packages are available on npm (Core 0.1.1 or newer, the other packages 0.1.0). These guides already cover the next release: anything marked **0.2** is not on npm yet.
Next.js generation currently uses Webpack. TanStack Start is experimental.
