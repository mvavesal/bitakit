Choose the features your app needs. These plugins contribute to the existing BitaKit runtime
and use its shared services, Actions and extension points.

These guides describe the **0.2 API in this checkout**. Use matching package versions; the
[local package setup](/docs/local-development) lets you try unpublished changes.
All package names below use the `@bitakit/` prefix.

## Available plugins

| Package           | Adds to your app                                                      |
| ----------------- | --------------------------------------------------------------------- |
| `shell`           | Application frame, layouts, slots, notifications and theme management |
| `app-preferences` | Settings pages, field controls, the settings route and navigation     |
| `quick-search`    | Plugin-owned search sources, navigation and recent history            |
| `scheduler`       | UI-free tasks, runtime schedule sources and in-process execution      |
| `devtools`        | Runtime inspection and development tools                              |

Shell's [Themes and appearance guide](/docs/concepts/theming) covers custom theme files and
the built-in manager. See [Theme reference](/docs/reference/theming) for its API and CSS contract.

[Quick Search reference](/docs/reference/quick-search) explains source contributions, user
preferences, concurrent results and history.

[Scheduler reference](/docs/reference/scheduler) covers task definitions, schedule sources,
execution, cancellation and server-only file watching.

See [Plugin identity and metadata](/docs/reference/plugin-metadata) for package identity,
provenance, descriptive fields and grouping in the Plugins page.

## Manage plugins in a running app

Use [Plugin manager](/docs/plugin-management) for supported runtime add, enable, disable and
remove operations. Use [Package manager](/docs/package-management) to activate trusted packages
from a catalog. Global provider and layout changes can require composition replacement.

For authentication, organizations, translation and email, see [Integrations](/docs/integrations).
The foundational runtime and build tools are listed under [Core packages](/docs/packages).

Dedicated guides will be added incrementally; this overview does not imply that every plugin
already has a complete public tutorial.
