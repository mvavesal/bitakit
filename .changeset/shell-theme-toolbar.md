Themes live at `/settings/theme` and Layout at `/settings/layout` (were `/settings/shell` and `/settings/shell/layout`). The theme select spans the row with the theme tools (customize, import, download, reset to default) below it as one icon toolbar with tooltips; long theme names are shortened while their source stays visible, and the menu matches the select's width.
